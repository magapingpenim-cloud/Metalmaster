# METALMASTER — сайт компании

Статический адаптивный сайт на HTML, CSS и JavaScript, готовый к публикации через Netlify.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация на Netlify
1. Откройте Netlify и выберите Add new site → Import an existing project.
2. Подключите GitHub-репозиторий `magapingpenim-cloud/Metalmaster`.
3. Build command оставьте пустой.
4. Publish directory укажите `.`.
5. Нажмите Deploy.

## Важно
- Фотографии загружаются с Unsplash, поэтому для них нужен интернет.
- Форма заявки подготавливает письмо в почтовом приложении пользователя и не сохраняет данные на сервере. Чтобы получать заявки напрямую, настройте Netlify Forms или подключите backend и укажите официальный адрес получателя.
- Телефон указан по предоставленной ранее концепции; проверьте его перед публикацией.
